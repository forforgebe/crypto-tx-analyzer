# 🔍 Crypto TX Analyzer

AI-powered crypto transaction analyzer using MiniMax AI.

## Features

- 🔗 Multi-chain support (Ethereum, BSC, Polygon, Arbitrum, Base, Optimism, Avalanche, Solana, TRON)
- 🤖 AI-powered analysis using MiniMax mimo-v2.5-pro
- 📊 Transaction type detection (transfer, swap, DeFi, NFT, bridge)
- 🚨 Risk assessment and rug pull detection
- 🐋 Whale movement analysis
- 📝 Custom context and questions

## Usage

1. Enter your MiniMax API key
2. Paste a transaction hash or explorer link
3. Select the blockchain
4. Click "Analyze Transaction"

## Quick Templates

- 🔍 **Rug Pull Check** - Analyze for rug pull indicators
- 🐋 **Whale Movement** - Track large transfers
- 🏦 **DeFi Interaction** - Analyze DeFi protocol usage
- 🖼️ **NFT Trade** - Analyze NFT transactions
- 🌉 **Bridge Transfer** - Analyze cross-chain bridges

## Tech Stack

- HTML/CSS/JavaScript (vanilla)
- MiniMax AI API (mimo-v2.5-pro)
- Vercel deployment
